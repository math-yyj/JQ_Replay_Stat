军棋复盘布阵统计工具 - 打包说明

1. 环境要求
   - 已安装 conda 并创建开发环境（假设命名为dev）
   - 环境中已安装 pyinstaller 和 openpyxl

2. 打包步骤
   在项目根目录下运行：
   ```
   conda activate dev
   python build.py
   ```

3. 输出文件
   打包完成后，在 dist 目录下生成：
   - 军棋布阵统计.exe (约 13 MB)

4. 使用方法
   直接运行 军棋布阵统计.exe 即可启动程序

5. 依赖说明
   本程序只依赖以下库（已包含在打包中）：
   - tkinter (Python 标准库)
   - openpyxl (Excel 导出功能)
   
   不包含重量级库，因此产物较小

6. 注意事项
   - 如果需要重新打包，请先清理 build 和 dist 目录
   - 打包脚本会自动排除不需要的模块
   - 生成的 exe 文件是独立的，无需安装 Python 环境
