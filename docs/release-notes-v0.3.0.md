# 军棋复盘布阵统计 V0.3.0 Release Note

本次版本围绕"复盘级分析"成体系升级：新增联众 .JQH 二进制复盘解析、QQ/联众
双平台的一键战术筛选与通用条件统计，并精简了主界面选项卡。

## 新增

### 联众 .JQH 二进制复盘解析
- 行棋记录区解码（步数头、坐标、Pass/GiveUp 哨兵）、坐标还原与严格规则推演；
- 终局判定：一方联盟两家出局 → "胜负已分"，否则 →"异常中断或和局"；
- 支持二人对局、开局 Pass/GiveUp、认输/扛旗/连跳判负清子；
- 与 200 组 .JQH/.JQH.TXT 配对回归：步数、坐标、终局判定全部一致。

### QQ 复盘完整分析（.jgs）
- 对局概览 / 四方布阵 / 行棋记录 / 子力统计（分值口径沿用军棋网分析器）；
- 军棋网 QQ 复盘分析器离线镜像（third_party，README 附来源与免责声明）。

### 联众文本复盘完整分析（.JQH.TXT）
- 玩家、17×17 棋盘、行棋、战斗结算、子力得失与评级。

### 常用模式一键筛选（QQ/联众双平台，N 选 1）
- **空炸司令/军长**：司令/军长在"什么都没吃 / 最大仅吃到连长"两种口径下被
  对手炸弹换掉即命中；细分"司/军主动撞炸 / 炸弹主动空炸"，列示炸方/被炸方；
- **装令复盘筛选**：旅⌀团 / 师⌀旅团 / 军⌀师旅 装大后，存活期内赚棋
  （对手在己方司令上折损师/军、或在己方军长上折损师）即命中；
  描述格式"X方，A装大（m步），B赚棋（n步）"；
- **骗炸复盘筛选**：装大后该子在己方司令未阵亡时被对手炸弹换掉，且被炸者
  非其幸存棋子中最大/并列最大；描述格式"X方，A骗炸（m步）"；
- 装令/骗炸共用窗口纯净性规则：装大至结果之间，对手不得有更大子力
  死于己方大棋（撞雷不算），否则该事件起点不成立；
- 结果表：每行一条事件、同局多行、复盘名/地址仅首行；双击打开复盘
  （等同资源管理器双击）、右键复制完整地址。

### 通用筛选条件统计
- 条件棋盘（格内或 / 格间且）+ 结果棋盘（首次满足 / 全部快照）批量统计，
  QQ 与联众复盘通用，范围随全局平台选择切换；
- 平台配色与方位：QQ 上橙红 / 左紫 / 下绿 / 右蓝；联众 下红 / 左绿 /
  上蓝 / 右黑；棋盘底色随平台联动。

## 调整
- 主界面选项卡精简为 11 个：QQ复盘解析、QQ复盘批量统计、联众复盘解析
  从主入口摘除（功能模块保留；批量统计能力由通用筛选条件统计覆盖，
  双击结果行可直接在官方客户端打开复盘）。

## 修复
- 联众推演轮次同步：开局 Pass/GiveUp 各占一轮；二人对局按两家交替轮转；
- 关键子追踪：阵亡记录不再被后续棋子落点覆盖；
- 平台切换时棋盘底色即时重绘；
- 布阵校验覆盖非行营位置的非法空位（JQNone）。
