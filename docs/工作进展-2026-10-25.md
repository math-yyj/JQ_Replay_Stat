## 二、项目概述

Python + Tkinter 桌面工具，解析 QQ（`.jgs`）与联众（`.jqh`）四国军棋复盘，提取四家 6x5 开局布阵，提供多维统计、条件筛选与布阵/复盘导出。

核心模块：

- `stats_gui.py`：主窗口、平台/方向切换、各统计面板。
- `src/layout_stats.py`：布阵统计内核、文本渲染、Excel 导出。
- `src/lianzhong.py`：联众 jqh 解码（布阵、用户名、主视角颜色）、jqs/jql 读写常量。
- `src/jgs_types.py`：QQ 棋子编码与短名单字映射。
- `test_sample/`：协议逆向与统计校验脚本及结果快照。
- `docs/`：README 截图、联众文件格式说明、本进展与对话记录。

## 三、本轮完成的主要工作

### 1. 布阵解析与统计内核

- QQ `.jgs`：解析 `PlayerInfoBlock` 四家布阵，跳过 1v1 对局与空布阵。
- 联众 `.jqh`：四色布阵解码，按 25 枚棋子/每色、行营空位、军旗位置等规则校验。
- 统计维度：棋子维度、QQ 颜色（兼座次）、联众颜色、联众先手方视角、QQ 号码、联众 ID、布阵筛选、条件概率。
- 主线（旗侧）视角：将军旗在右侧大本营的布阵镜像后与左侧合并，实现旗侧归一化。

### 2. 数据校验与异常处理

统一规则（`BasePanel._layout_has_invalid_piece` 与 `src/layout_stats.py`）：

- 非行营位置出现 `JQNone`（0x00）→ 异常，跳过并计入异常复盘。
- 非行营位置出现未知棋子编码 → 异常。
- 布阵缺少军旗 → 异常。
- 四家布阵不全（非 1v1 且非 4 家）→ 异常。

该校验已覆盖 QQ 颜色/号码、联众颜色/先手/ID、按布阵筛选、条件概率筛选全部面板。此前仅基础统计面板校验，本次修复了其余面板漏检的问题。

### 3. 平台联动与选项卡

- 选项卡顺序：棋子维度 → QQ 颜色（兼座次） → QQ 号码 → 联众颜色 → 联众先手方视角 → 联众 ID → 按布阵筛选 → 条件概率筛选。
- 主视角统计入口隐藏（逻辑保留）。
- 平台切换时选项卡按语义映射，不跳变；隐藏页自动回落到棋子维度。
- 通用页（棋子维度、按布阵筛选、条件概率筛选）在两种平台下始终可用。

### 4. 按布阵文件筛选（QQ/联众公用）

- 加载 `.jqs` / `.jql` 布阵文件并显示 6x5 网格。
- 按复盘原始数据逐格比对，不做顺逆时针旋转，不做旗侧镜像；行营格跳过。
- 支持 `.jgs` 与 `.jqh` 混合扫描，显示“已处理/总数”进度。
- 汇总显示匹配布阵数与去重复盘数（`去重复盘: M/N`）。
- 导出复盘时按文件去重，避免同名覆盖。
- 所有文件对话框绑定父窗口并保存/恢复主窗口 geometry。

### 5. 条件概率筛选

- 左侧 12 种棋子（2x6 按钮，RadioButton 单选行为），中间条件面板，右侧结果面板。
- 左键放置、右键移除；第 0 行禁止弹，第 1-3 行禁止雷/旗，第 4-5 行全开放。
- 结果为原始命中计数，不再做棋子数量归一化（用户明确要求移除 factor）。
- 展示格式与颜色统计一致：每行两枚、按频率降序、`_rank_color` 分级着色。
- 按钮顺序：统计 → 清空所有 → 导出复盘 → 导出布阵 → 联众/QQ 格式单选。
- 导出布阵按布阵内容去重；导出复盘按文件去重。

### 6. 黑白名单

- QQ 号码统计：白名单/黑名单至少填写一项，命中后仅统计对应布阵。
- 联众 ID 统计：用户名经 XOR 累积链解码后匹配，支持导出复盘与布阵。
- 两者汇总均输出去重复盘数量。

### 7. 去重

- 全局“去除重复布阵”勾选框，默认开启；切换时清空全部统计结果。
- 去重键为 30 格棋子内容元组（`_layout_to_key`），跨文件、跨面板生效。
- 导出布阵同样按内容去重，修复了此前导出未去重的问题。

### 8. 联众协议逆向

用户名解码（0x64 起连续 80 字节 = 红/绿/蓝/黑 各 20 字节）：

```
encoded[i] = ((encoded[i-1] + plain[i]) % 0x100) ^ 0x13
plain[i]   = ((encoded[i] ^ 0x13) - encoded[i-1]) % 0x100
```

仅红方首字节为明文，后续所有字节（含绿蓝黑首字母）都依赖前一编码字节。

主视角颜色（0xB7 / 0xB8）：

```
color = ((data[0xB8] ^ 0x13) - data[0xB7]) % 0x100
映射：0=红, 1=绿, 2=蓝, 3=黑
```

测试脚本：`test_sample/test_main_color.py`，结果见 `test_sample/test_main_color_result.txt`（10 个样本全部解码成功）。

### 9. 导出格式

- `.jqs`：112 字节文件头（`0x00` 填充），布局位于 `0x370`，行跨度 17 个 uint32，总长 1264 字节，行营为 `0x00`。
- `.jql`：20 字节文件头 `51 51 47 61 6D 65 20 4A 51 4C 20 46 69 6C 65 00 57 04 00 00`，30 字节布局位于 `0x14`，一格一字节，总长 50 字节。
- 导出命名含时间戳，冲突时追加序号。

### 10. UI 规范

- 棋子单字显示（“弹”替代“炸”，“旗/雷/司/军/师/旅/团/营/连/排/兵”）。
- 百分比：100% 显示为 ` 100%`，其余 `%5.1f%%`；计数模式宽度 `1+int(log10(total))`。
- 排名颜色：top1 `#FF0000`，top2 `#7F0000`，top3 `#3F0000`，其余黑色。
- 每格每行固定两枚棋子。
- 行营格统一灰色空白，不出现复选框。
- 行列下标对外从 1 开始显示。
- 单元格尺寸、字体、面板宽高按第 0 行比例动态缩放。
- 所有对话框、文件选择器、导出窗口继承父窗口并保护主窗口尺寸。

### 11. QQ 完整对局解析（新增）

- 新增后端模块 `src/qq_replay.py`：解析 `.jgs` 4×88 玩家块、30 字节布阵、0x19B/0x19C 指令流。
- 方位推导：枚举 24 个“颜色→方位”双射，按行棋自洽率取最优，颜色字节做平票兜底。
- 行棋结算：吃子、被吃、同尽、炸杀、中炸、挖雷、触雷、扛旗；超时判负、战败、退出、连续两次未行棋判负；按最终存活判定胜负。
- 新增 GUI 选项卡“QQ复盘解析”（仅 QQ 模式显示）：对局概览、四方布阵、行棋记录、子力统计；支持导出完整 JSON 与复盘 v2.0 文本。
- 新增命令行入口：`python -m src.qq_replay <file.jgs> [--json ...] [--text ...]`。
- 联众复盘对局解析保持空缺。
