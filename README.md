## 已支持功能

* [x] QQ复盘文件(.jgs)的四家布阵内容解析
* [x] 联众军棋复盘文件(.jqh)的四家布阵内容解析
* [x] 布阵统计（多维度筛选）
* [x] 棋子维度统计（12选1单选）
* [x] 主线（旗侧）视角统计
* [x] 布阵数据校验（空位/非法编码/缺军旗/空布阵）
* [x] 高级筛选（组合条件筛选 + 按布阵文件筛选）
* [x] 条件概率筛选（条件/结果格子交互式分析）
* [x] QQ号码白名单/黑名单筛选
* [x] 联众ID白名单/黑名单筛选
* [x] 去除重复布阵
* [x] 百分比/数量显示模式切换
* [x] 联众用户名解码（XOR累积加密）
* [x] 导出布阵/导出复盘双通道导出

## 统计面板

程序提供以下统计面板，根据平台（QQ/联众）自动显示：

| 面板 | QQ模式 | 联众模式 | 说明 |
|------|--------|----------|------|
| 棋子维度统计 | 显示 | 显示 | 12选1单选，只统计选中棋子在各位置的出现频率 |
| QQ颜色(兼座次)统计 | 显示 | - | 按颜色/座次筛选（红先手位/紫二号位/绿三号位/蓝四号位） |
| QQ号码统计 | 显示 | - | 白名单/黑名单筛选特定玩家 |
| 联众颜色统计 | - | 显示 | 联众模式按红/绿/蓝/黑筛选 |
| 联众先手方视角 | - | 显示 | 按座次(先手位/二号位/三号位/四号位)统计 |
| 联众ID统计 | - | 显示 | 按用户名白名单/黑名单筛选 |
| 高级筛选 | 显示 | 显示 | 组合条件筛选、按布阵文件筛选，支持导出布阵/复盘 |
| 条件概率筛选 | 显示 | 显示 | 标记条件/结果格子，分析条件概率分布 |

**平台切换时选项卡自动对应，不会跳变。**

## 方向与镜像

提供三种方向选项：

| 方向 | 说明 |
|------|------|
| 逆时针 | QQ模式默认。不镜像显示 |
| 顺时针 | 联众模式默认。镜像显示（列顺序翻转） |
| 主线（旗侧）视角 | 将军旗位于右侧大本营的布阵镜像翻转后叠加到左侧统计，实现旗侧归一化视角 |

**镜像规则：**
- QQ模式：逆时针=不镜像，顺时针=镜像
- 联众模式：顺时针=不镜像，逆时针=镜像
- 主线模式：始终不镜像（内部已处理左右旗合并）

## 统计结果显示

- 每个格子显示棋子出现频率，按百分比降序排列
- 双列显示：top1 top2 / top3 top4 / ...
- 颜色渐变：top1=红, top2=暗红, top3=更暗红, 其它=黑
- 支持百分比/数量两种显示模式切换
- 行营位置显示为灰色空白

## 数据校验

QQ复盘布阵校验规则：
- 非行营位置出现空位(JQNone) → 标记异常
- 非行营位置出现未知棋子编码 → 标记异常
- 布阵缺少军旗 → 标记异常
- 四家布阵不全（非1v1且非4家） → 标记异常

## 其他行为

- 切换文件夹或切换平台时，所有统计结果自动清空
- 切换方向时，保留已有统计结果，仅重新渲染（镜像翻转）
- 统计过程中动态显示进度（已处理/总数）
- 异常复盘合并提示，每类最多列10个文件名

## 高级筛选

- **组合条件筛选**：在6x5网格中勾选棋子，交集匹配
- **按布阵文件筛选**：加载 .jqs/.jql 布阵文件，搜索匹配的复盘
- 支持导出布阵（按布阵去重）和导出复盘（按文件去重）

## 条件概率筛选

- 6x5网格，每个格子可标记为"条件"、"结果"或"忽略"
- 条件格子：勾选棋子作为筛选条件
- 结果格子：显示匹配布阵中该位置的频率分布
- 支持清空所有勾选，复位为忽略状态
